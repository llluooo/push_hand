# 主动重心与低台失足优化汇总

日期：2026-10-23。状态：用户在前后失足调校后回复“OK 写入日志吧”，据此完成本轮阶段记录；保留当前版本作为后续试玩与地图设计的基线。

对应计划：[主动重心控制与低台失足表现优化](../项目计划/2026-10-21-主动重心控制与低台失足表现优化.md)。沿用 Unity 2022.3.62f3c1、原工程及 `feature/push-hands-greybox` 分支，未升级依赖、修改 AGENTS.md 或启动模型训练。

## 最终决定

- 重心控制采用最终确认的 B：普通幅度倾身及及时收回应可控，持续极限前倾或后仰仍能失衡；不采用无限稳定或按键保持时长直接判负。
- 场地采用独立低台：双方各站一座小台，救身迈步容易踩空。后续地图可以改变几何，仍按真实支撑决定落脚或摔落，不强制每次判负都坠落。
- 先迈步者负，迈步时唯一裁决；随后停止主动发力及技巧，保留有限观察，展示身体动作与实际落地后再开放重开。

## 主要工作与最终参数

- 主动倾身改为有限速度建立，保留持续极限动作的额外重心投入；回归普通倾身、短按满幅后收回、反向调整，以及静止对手仍能被有效推动。
- 新增 `PhysicalArena`，使用编辑器 API 定向更新原场景中的两座站台、下方落地面与出生引用，保留现有人偶及预制体。
- 保护步沿实际失衡方向和已有速度选择目标。脚中心越沿、擦碰台侧、尚未完成抬落，不直接当作全脚踩空；实际失去支撑后撤去足部锚点及站立辅助，保留关节限位与实际动量。
- 保护步开始保留已投入的躯干姿态，实际落脚后逐渐恢复，避免瞬间拉回直立。足步落脚与身体摔落接地分别触发反馈；躯干由台面真实向上承托也可完成摔倒展示，侧壁擦碰不算承托。
- 默认至少约 3 秒展示，覆盖实际落地与短暂停留；8 秒异常兜底开放重开并记录警告，不伪报落地。提前按键不截断动作，也不缓存为自动重开。
- 第一人称倒地观察保持稳定方向，排除自身肩胸遮挡；另一方仍可看见身体。重开恢复姿态、驱动、身体层、足部锚点、计时与反馈。

## 试玩反馈与问题修正

- 用户反馈台面略大、迈步后不容易摔下，先由 0.52×0.46 米缩至 0.46×0.42 米；随后继续反馈前迈踩空，但后仰和推退对手不明显。
- 复现后发现，旧布局脚底前后覆盖约为 [-0.16, 0.21] 米，而台沿为 [-0.21, 0.21] 米，后方额外留出约 5 厘米。后仰保护步目标约 z=-0.315 米，脚尖仍能搭台，随后恢复站姿；前倾目标约 z=0.380 米，实际脚部已离台。
- 单独前移台面虽然改善后退，却使前倾也更容易站住，该实验未采纳。最终保留前沿 z=0.21 米，将后沿收至 z=-0.17 米，对应当前 0.46×0.38 米及前移 0.02 米的布局；未增加步幅或施加额外坠落力。
- 新增独立出生偏移 `SpawnOffsets`，按平台旋转保存米制偏移、不随台面缩放，避免重新出生于台心抵消台沿调校。补充双方换边的严格前后失足和静止防守回归，修补旧测试允许后仰迈步恢复站立的覆盖不足。
- 修正原生物理参数在保存人偶载入后丢失的问题：初始化恢复 16／8 求解迭代及 12 最大角速度，使真实预制体、场景和程序创建人偶采用一致设置。此前包内未摔落的运行未记为通过。
- 修正曾按未来目标和 65% 动作进度提前开始坠落的问题，改由实际脚部条件决定。排查中使用未公开编辑器 API 导致的编译失败已修正；最终报告确认新增测试实际执行，不采信编译失败期间旧程序集的假绿结果。
