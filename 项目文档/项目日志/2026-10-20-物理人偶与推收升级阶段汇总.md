# 物理人偶与推收升级阶段汇总

日期：2026-10-20。最新状态：本轮收尾。已完成独立物理场景、人偶、原生测试及 Windows 试玩包；用户试玩后反馈“问题不少”，当前玩法尚未验收，不认定为满意或稳定的可交付版本。用户将开新聊天继续优化与训练，本轮停止工程修改和训练。正文前段保留首次源码交付受阻的历史记录，当前结果以文末试玩交付与交接部分为准。

## 最终确认

- 沿用原 Unity 2022.3.62f3c1 与工程，采用受控刚体／关节训练人偶，不更换物理引擎、不引入正式人物美术。
- 合法对抗仅发生在手掌、前臂之间，胸腹不作为推力目标。收手与身体后缩可撤去接触；推空后的前冲惯性应保留，过猛前倾可能迈步判负。
- WASD／左摇杆继续控制主要重心；Q／LB 触发双手收力后撤，E／RB 触发双手假推。单次按下执行完整动作，恢复且松开后可再次使用，不限制每局次数。
- 本轮先建立可试玩物理系统，再做身体协调与玩法调优首轮机器学习实验；模型不替玩家选择技巧时机，双方能力相同，每局参数与模型固定。
- 用户明确要求更新 AGENTS.md，已增加“交流明确 → 确认落盘 → 正式搭建 → 验证 → 阶段日志”的工程流程。确认方案先写入 `2026-10-20-受控物理人偶与推收博弈升级.md`，随后开展源码实施。

## 主要工作

- 新增独立 Physics 程序集及 PhysicalFighter：20 段刚体、总质量 70 千克；骨盆、腰胸、颈头、肩带和四肢链；肘膝主要弯曲轴限制、有限肌肉驱动、足部有限站姿约束；实际刚体质量加权重心与速度用于平衡趋势。
- 合法碰撞仅保留双方手掌／前臂组合，身体自碰撞过滤在加载后重建；对准目标限制距离、追踪速度与伸手范围，不转为胸腹目标。
- TechniqueState、PhysicalRound 管理技巧、松开保护、完整三秒准备、暂停恢复和唯一裁决；PhysicalInput、PhysicalMatch 接入旧设备绑定、双手柄分屏及键鼠开发验证。键鼠靶显式轻推，避免将收手状态误称为防守接触。
- PhysicalBuilder 提供 Editor API 独立场景、预制体、材质／参数和 Windows 构建入口；未覆盖旧灰盒或原 Build Settings。新增独立中文字体源及许可证，保留旧灰盒字体。
- PhysicalRecorder 提供显式 F4 本地记录；输入与平衡结构增加序列化标记，补充 JSON 往返回归；PhysicalContact 单独放置于同名脚本，消除场景脚本持久化布局风险。
- LinearBalancePolicy 提供 10 维观察、2 维有限修正；PhysicalExperiment 通过真实 Physics.Simulate 执行换边、扰动、推收、假推与留出场景。Training 工具使用标准库交叉熵搜索 22 个策略参数，再独立评估三个小范围参数，不安装新运行依赖。
- 模型晋级要求留出损失改善至少 2%、失败不增加、最低骨盆高度不低于 0.70 米，并检查站立成功、真实接触、撤手分离和前冲惯性；无效或未验证模型回退基础控制器。没有生成或启用已训练模型。
- 新增源码编译工具、源资源元数据准备工具，更新试玩说明及原说明入口；新增源资源配套 `.meta`，没有编辑序列化场景或预制体。
