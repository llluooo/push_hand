# 灰盒界面字体

来源：[Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)。
许可证见 OFL.txt。使用 fontTools 固定为 400 字重并按界面字符裁剪，修改后的字体名为 PushHands UI。
原始文件 SHA-256：`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`。
重新生成：将原始 NotoSansSC[wght].ttf 保存到 Artifacts/Sources/NotoSansSC.ttf 后运行 `python Tools/PrepareUIFont.py --physical`；随后通过编辑器生成或更新 TMP 字体资源。
